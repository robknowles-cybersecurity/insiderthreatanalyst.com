# SITE PAGE MANIFEST (PE-279 item 4b): the one list of the site's pages.
#
# tools/build-nav.sh reads this file. Everything else that needs the page list
# (search index, anchor check, sitemap) asks build-nav.sh for it with --list,
# so a new page is added HERE and nowhere else.
#
# Format, one entry per line:
#   page <path>               a page that carries the site nav
#   exclude <path> <reason>   a page under the webroot that deliberately has no
#                             site nav; the reason is required
# Blank lines and lines starting with # are ignored. Paths are relative to the
# site root. Anything else is an error, and build-nav.sh names the line.
#
# A page whose path must not appear in this public file excludes itself
# instead, with  <!-- NAV:NONE: <reason> -->  in its own HTML. That keeps this
# file and tools/build-nav.sh identical on the hub and on the public mirror,
# with no redacted copy to hand-edit.
