Changelog

Version history for the Insider Threat Analyst Career Framework. This site is actively maintained and updated based on community feedback, new research, and evolving practice.

v1.5.0 2026-09-04
  • New The KSA → NICE crosswalk is published. Every active KSA is now mapped to NICE Framework Components v2.2.0 (NIST SP 800-181r1), with the primary work role, the specific TKS statements cited, a confidence rating, and which review tier decided each row. The page carries its own provenance block: source file, sha256, download date, and the method in full. It is versioned, indexed, and in the nav for the first time — it had been an unlinked scaffold since v1.3.1.
  • Changed Retired NICE identifiers remapped to their v2.2.0 successors (PE-253). All five: K0001→K0674, K0002→K0721, K0005→K0682. The last two needed a different treatment. The successors for S0085 and T0223 — S0619 and T1306 — already existed here as separate KSAs: they are the Level 3 audit statements, while S0085 and T0223 are the Level 2 pair. Both levels are kept; nothing was merged away. The two Level 2 rows now carry ITA-native identifiers in this framework’s own scheme, S-AUD01 and T-AUD01, and cite S0619 and T1306 as their NICE source. Every retired id still resolves — old links and searches land on the renamed row.
  • Removed A-G02 merged into A-IRPB01. Both described designing insider-specific incident response playbooks; the more precise statement survives.
  • Removed A-G01 merged into A-CAG01. Both described leading crisis action groups; A-CAG01 survives because it spells the term out instead of leaving the acronym unexpanded. Merged ids are tombstoned, never reused — they keep their place on the framework and matrix pages, and links to them still resolve.
  • Changed Active KSA count is now 143 (+2 merged). It was 145 at v1.4.0.
  • Changed ATT&CK v19 unmappable techniques resolved from the pinned source. The five carried over from the July v19.1 re-tag were resolved against the pinned enterprise-attack-19.1.json bundle, its sha256 verified against the July pin before anything was read from it. Four were revoked with a single unambiguous successor and have been remapped: T1070.001→T1685.005, T1562→T1685, T1562.001→T1685, T1562.011→T1685.003. Because T1562 and T1562.001 both revoke into T1685, their two entries collapsed into one carrying the union of their SOFIT indicators, so Category B is now 43. The fifth, T1548, turned out not to be revoked at all — only its defense-evasion tactic tag, which v19 retired, needed correcting to privilege-escalation. No defense-evasion tags remain.
  • Removed No third-party fonts. Every page now renders in a system font stack, defined once in the shared stylesheet. The hosted-webfont stylesheet links and their preconnect hints have been removed site-wide: there are zero external origins for fonts anywhere on this site, and no font request leaves the reader’s machine. The crosswalk page shipped this way; it is now the site standard.
v1.4.0 2026-09-04
  • New Site search. Every public page is searchable now — the Search button in the nav, or press /. It is full text, and it reaches the content the Framework Explorer, KSA matrix, and competency clusters render from JavaScript rather than ship as HTML — the part of this site that no search had ever been able to see. Results link to the section that matched, not to the top of the page, and the term you searched for is highlighted where you land. Built with Pagefind, served from this site: the index is a static file, the search runs in your browser, and no query is sent anywhere.
  • New INTRA (Insider Threat and Risk Architecture) added to the standards and professional bodies resources on the Program Hub — a European jurisdiction layer for insider risk. 110 measures across nine pillars, mapped to 34 jurisdictions, with a read source on every row, published as browsable pages and as JSON. Free, CC BY 4.0.
  • New Alessandro Aledda credited on Contributors for INTRA.
  • New The site carries its first named, attributed review: Alessandro Aledda, who works this problem in a different jurisdiction and built his own framework for it, called this the best map of the field he has found. Quoted with his permission, on Contributors — the reviews page is tongue in cheek, and a real review does not belong in it.
  • New A-AGENT01 — Ability to investigate AI agents as non-human insiders. The framework has described AI agents as insider-like access holders since v1.3.2; this is the first KSA that says what an analyst actually does about it: attribute agent actions to a unique agent identity and its accountable human sponsor, reconstruct the input to tool-call to data-access chain, and find over-privilege, agent sprawl, indirect prompt injection, and unauthorized tool use. Level 4, custom source, AI/ML cluster. Two sources added to that cluster with it: Microsoft's Least privilege for AI agents and How Vulnerable Are AI Agents to Indirect Prompt Injections?. KSA count is now 145; the NICE crosswalk and Start Here counts follow.
  • Changed Bidemi Ologunde's entry now records the second round — the investigative half of the AI-agent question, which became A-AGENT01, and the sources behind it.
